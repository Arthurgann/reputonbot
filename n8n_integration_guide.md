# Интеграция с n8n для обработки жалоб через нейросеть

## Обзор

Созданная система позволяет обрабатывать тексты жалоб через нейросеть GPT-4.1-mini. n8n отправляет текст жалобы в backend, который:
1. Получает платформо-специфичные инструкции из Supabase
2. Отправляет текст жалобы и инструкции в OpenAI API
3. Возвращает сформированный ответ в формате JSON

## Архитектура

```
n8n → /webhook/n8n → Supabase (инструкции) + OpenAI API → Ответ в формате JSON
```

## API Endpoint

**POST** `/webhook/n8n`

### Принимаемый формат (payload):
```json
{
  "text": "Текст жалобы от пользователя",
  "platform": "название_платформы", 
  "business_type": "тип_бизнеса",
  "tg_user_id": "ID пользователя в Telegram (опционально)"
}
```

### Возвращаемый формат:
```json
{
  "complaint": "Сформулированная жалоба",
  "instruction": "Инструкция по подаче жалобы",
  "tips": ["Совет 1", "Совет 2", "Совет 3"]
}
```

## Настройка в n8n

1. Добавьте HTTP Request node
2. Установите:
   - Method: POST
   - URL: `http://ваш-сервер.com/webhook/n8n`
   - Content-Type: `application/json`
3. В теле запроса передайте JSON с текстом жалобы и другими параметрами

## Пример использования в n8n

```json
{
 "text": "Пользователь оставил негативный отзыв: 'Ваш товар ужасный, вы мошенники!'",
  "platform": "wildberries",
  "business_type": "e-commerce"
}
```

## Технические детали

### backend/services/llm.py
- Реализует вызов OpenAI API
- Использует модель `gpt-4.1-mini`
- Возвращает JSON с полями `complaint`, `instruction`, `tips`

### backend/main.py
- Добавлен маршрут `/webhook/n8n` для обработки запросов от n8n
- Извлекает текст жалобы из payload
- Получает системный промпт из Supabase
- Логирует взаимодействия

### backend/services/db.py
- Функция `get_platform_prompt()` получает платформо-специфичные инструкции из Supabase
- Если инструкция для платформы отсутствует, используется fallback

## Тестирование

Для тестирования системы можно использовать скрипт `test_full_integration.py`, который проверяет все компоненты интеграции:

```bash
python test_full_integration.py
```

## Безопасность и надежность

- В случае ошибок API OpenAI возвращается заглушка с примерным ответом
- Все взаимодействия логируются в Supabase
- Используется API-ключ OpenAI из переменных окружения
